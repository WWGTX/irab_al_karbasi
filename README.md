إعراب الكرباسي (Irab Al-Karbasi)
مستودع مفتوح المصدر يهدف إلى توثيق ورقمنة إعراب القرآن الكريم وفقاً للمنهج الجعفري الشيعي، بالاعتماد بشكل أساسي على المدونات والموسوعات اللغوية والتفسيرية في التراث الشيعي، وعلى رأسها موسوعة "إعراب القرآن الكريم" للشيخ محمد صادق الكرباسي.
يوفر هذا المستودع كافة البيانات اللغوية والنحوية لآيات الكتاب المجيد مجموعة في ملف قاعدة بيانات (DB) واحد جاهز للاستخدام، ليكون مرجعاً تقنياً سريعاً للباحثين ومطوري التطبيقات الإسلامية دون الحاجة لمعالجة ملفات نصية معقدة.
الميزات الرئيسية
 * إعراب شامل: تفصيل نحوي دقيق لآيات القرآن الكريم كلمة بكلمة.
 * منهجية معتمدة: تبني الآراء النحوية والتوجيهات الإعرابية التي تتوافق مع مدرسة أهل البيت (عليهم السلام) وتفاسيرهم.
 * ملف قاعدة بيانات جاهز: توفير البيانات بصيغة .db (مثل SQLite) يسهل ربطها مباشرة بتطبيقات الهواتف الذكية (Android/iOS) ومواقع الويب.
 * سرعة البحث: إمكانية الاستعلام (Query) عن القواعد النحوية، والأدوات، والكلمات بسرعة فائقة عبر أوامر SQL.
هيكلية المستودع
يحتوي المستودع على ملف قاعدة البيانات الأساسي إلى جانب ملفات التوثيق فقط، لتسهيل التحميل والاستخدام المباشر:
irab_al_karbasi/
├── irab_al_karbasi.db    # ملف قاعدة البيانات الشامل للإعراب
├── README.md             # ملف التوثيق والشرح
└── LICENSE               # رخصة الاستخدام

نموذج للاستعلام من قاعدة البيانات (SQL Query)
ملف irab_al_karbasi.db مصمم بجداول مترابطة (مثل رقم السورة، رقم الآية، الكلمة، الإعراب). يمكنك استخراج إعراب أي آية (مثال: سورة الفاتحة، الآية 2) باستخدام استعلام بسيط:
SELECT word, irab_text 
FROM quran_irab 
WHERE surah_number = 1 AND ayah_number = 2;

النتيجة المتوقعة:
| word | irab_text |
|---|---|
| الْحَمْدُ | مبتدأ مرفوع وعلامة رفعه الضمة الظاهرة على آخره. |
| لِلَّهِ | اللام: حرف جر مبني على الكسر. الله: لفظ الجلالة، اسم مجرور وعلامة جره الكسرة... |
الاستخدام والتثبيت
يمكنك استنساخ المستودع للحصول على ملف db ودمجه في مشروعك فوراً:
# استنساخ المستودع
git clone https://github.com/WWGTX/irab_al_karbasi.git

# الدخول إلى المجلد
cd irab_al_karbasi

بعد تحميل المستودع، يمكنك فتح ملف irab_al_karbasi.db باستخدام برامج مثل DB Browser for SQLite لتصفح البيانات، أو ربطه مباشرة بلغة البرمجة الخاصة بمشروعك (Python, Java, Swift, PHP وغيرها).
